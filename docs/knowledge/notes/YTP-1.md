# YTP-1: Spring Boot project skeleton with "alive" home page

## Notes

## Debrief summary

### 2026-10-10

**What went well**
- Overall the ticket went well.
- Switching from Spring Boot 3 to 4 during planning was the right call: Boot 3 is past OSS support, and migrating later would have been harder.

**What was hard or surprising**
- More work than expected for a skeleton, mostly the re-plan from Boot 3 to Boot 4, which felt heavy for a project this size.

**What to change**
- Nothing. The re-plan was a deliberate trade-off, not a process gap.
